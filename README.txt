BLACK CLIENT V3 — GitHub Pages

1. Rozpakuj ZIP. Wgraj index.html, style.css, script.js, .nojekyll oraz katalogi assets i downloads do głównego katalogu repozytorium.
2. GitHub: Settings > Pages > Deploy from a branch > main > / (root) > Save.
3. Po opublikowaniu każdy przycisk Pobierz wskazuje lokalny downloads/BlackClient.exe i używa atrybutu download. Nie wymaga zewnętrznego linku ani backendu.
4. Jeżeli przeglądarka ostrzega przed plikiem EXE, nie omijaj ostrzeżenia. Zweryfikuj plik przed uruchomieniem oraz upewnij się, że masz prawo go publicznie udostępnić.

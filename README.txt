BLACK CLIENT — WEBSITE V2

1. Rozpakuj archiwum.
2. Prześlij wszystkie pliki i folder assets do głównego katalogu repozytorium GitHub.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Aby włączyć pobieranie, w script.js ustaw DOWNLOAD_URL na adres HTTPS zweryfikowanego wydania klienta.

W paczce nie ma pliku BlackClient.exe. Grafiki logo i tła pochodzą z poprzedniej wersji strony. Nie są używane zewnętrzne biblioteki ani fonty. Strona działa również lokalnie po otwarciu index.html.
